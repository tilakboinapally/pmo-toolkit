STEP 1

Deck questionnaire

These answers become the cover slide, the summary copy, and the brief for the draft assistant.

The timeline is drawn by quarter between the project start and end dates — a project can run up to 2 years (8 quarters).

STEP 2

Brand kit — common elements

Applied to every slide: logo, colors, company name, and footer.

No logo yet — upload one and it appears on the cover and roadmap slides, in the preview and the .pptx.

STEP 3

Epics & features

One row per epic, with start and end dates — or import the whole list from a CSV. Features sit inside their epic and land as milestones on the bar.

One row per epic or feature. Columns: type, name, owner, start, end, status, summary, epic, date — a feature row names its epic in the epic column and its landing date in date. Dates can be 2027-03-15, 3/15/2027, or Q1 2027. Importing replaces the list below and widens the Step 1 project dates to fit.

STEP 4

Draft assistant — connect an LLM

Your questionnaire answers and epic list become the prompt. Connect your own LLM key and the model writes the executive summary and speaker notes — or draft locally with no key. Edit anything before you download.

The key is held in this tab only — it goes straight to the provider together with your answers, and is never saved.

SUITE
How the suite fits together — one shared spine
Every module reads from the same project file, so nothing gets typed twice.

      

        
The questionnaire, brand kit, epics, features, and tasks live in one project. Your roadmap epics seed the Gantt plan; the epics, features, and Gantt milestones prefill the weekly status report; the brand kit (logo, colors, footer) and the .pptx engine are shared by every deck. Saving the project file in the Roadmap module (Step 5) carries the tasks, the current status report, and its archived-week history too — reopen it and every module picks up where you left off.

        
Roadmap Deck
Questionnaire → cover, timeline / Now-Next-Later / Executive slides. Epics & features, CSV import, 2-year date-based timeline, LLM draft assistant, pre-flight checks.
Live

        
Gantt Chart
Tasks with owners, dates, % complete, finish-to-start dependencies, milestones, and a computed critical path. Seeds from your epics, imports its own CSV, exports a plan slide in the same brand kit.
Live

        
Status Report Deck
The weekly PMO artifact: pick the reporting week, set RAG health with a one-line reason, accomplishments, milestones hit and upcoming (prefilled from epics, features, and Gantt milestones), risks and issues with owner and mitigation, decisions needed, and next steps. Archiving a week starts the next one prefilled from it, and the branded 2-slide .pptx uses the shared brand kit.
Live

        
RAID Log
Risks, assumptions, issues, and dependencies as a register, plus a one-pager slide for steerco. Feeds the status deck's risks section.
Next

        
Charter & Kickoff Deck
Scope, objectives, success criteria, team, and timeline — mostly a new arrangement of answers the questionnaire already collects.
Planned

        
Portfolio Dashboard
Health rollup across several saved projects for the PMO / executive view. Only worth building once you have a few projects saved.
Later

REPO
Publishing it as one repo
One new repo, separate from the CMS checklist (different audience). Suggested shape when it moves to GitHub:

      

        
modules/roadmap · modules/gantt · modules/status — one folder per module
shared/ — brand kit, project data model, .pptx engine, CSV import
templates/ — the downloadable CSV templates
Same flow as your other utilities: you create the repo, add it to the GitHub App, the code gets pushed, and Pages hosts the site.
